# Бот «Интересные факты» с памятью

Telegram-бот, с которым можно просто разговаривать. Он знает интересные факты, находит их **по смыслу** (а не по совпадению слов) и запоминает то, что вы ему рассказали.

```
Вы:  Что можно хранить тысячелетиями и не бояться порчи?
Бот: Мёд! В египетских гробницах находили горшки с мёдом возрастом более 3000 лет, и он оставался съедобным.

Вы:  Запомни, что мне нравится жёлтый VW Beetle
Бот: Запомнил: тебе нравится жёлтый Volkswagen Beetle.

Вы:  Что ты обо мне помнишь?
Бот: Ты рассказывал, что тебе нравится жёлтый Volkswagen Beetle.

Вы:  Забудь про Beetle
Бот: Удалил из памяти, что тебе нравится жёлтый Volkswagen Beetle.
```

## Что умеет бот
- **Вести беседу.** Отвечает живым языком, помнит последние реплики разговора и отвечает цитатой на ваше сообщение.
- **Отвечать по базе фактов.** Находит близкие по смыслу факты и строит ответ на них. Если в базе ответа нет, честно говорит об этом.
- **Запоминать.** «Запомни, что ...» сохраняет запись в векторную память. Почти одинаковые записи не дублируются.
- **Вспоминать.** Использует сохранённое в ответах и по запросу рассказывает, что помнит о вас.
- **Забывать.** «Забудь про ...» или «удали ...» удаляет запись. Если подходящих несколько, бот уточнит, какую именно.
- **Хранить память отдельно для каждого пользователя.** Чужие записи бот не видит и не может удалить.

Команды: `/memory` покажет всё, что бот о вас помнит, `/search запрос` выдаст сырые результаты поиска с релевантностью, `/reset` начнёт разговор заново (память останется), `/help` даст подсказку.

## Как это устроено
1. Текст превращается в вектор (1536 чисел) моделью эмбеддингов OpenAI `text-embedding-3-small`.
2. Pinecone хранит векторы с текстом в двух namespace: `facts` для базы фактов, `memory` для воспоминаний пользователей.
3. На каждое сообщение бот ищет ближайшие факты и воспоминания и передаёт их языковой модели как контекст.
4. Модель сама решает, когда нужно записать, прочитать или удалить воспоминание, и вызывает для этого инструменты `remember`, `recall`, `list_memories`, `forget`.

## Технологии
- Python 3.13
- [Pinecone](https://www.pinecone.io): serverless-индекс, метрика cosine
- OpenAI: эмбеддинги и чат-модель с вызовом инструментов (подходит и любой OpenAI-совместимый шлюз)
- python-telegram-bot

## Установка
```bash
py -3.13 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```
Затем заполните `.env`. Файл `.env` в git не попадает.

## Настройка
Понадобятся три ключа:
- **Pinecone**: ключ из раздела API Keys в консоли. Индекс создавать вручную не нужно, он создастся при первой загрузке данных.
- **OpenAI**: ключ с платформы OpenAI.
- **Telegram**: токен бота от [@BotFather](https://t.me/BotFather).

| Переменная | Смысл |
|---|---|
| `PINECONE_API_KEY` | ключ Pinecone |
| `PINECONE_INDEX_NAME`, `PINECONE_CLOUD`, `PINECONE_REGION` | параметры индекса (по умолчанию `interesting-facts`, `aws`, `us-east-1`) |
| `PINECONE_NAMESPACE`, `PINECONE_MEMORY_NAMESPACE` | namespace для фактов (`facts`) и памяти (`memory`) |
| `EMBEDDING_API_KEY` | ключ OpenAI или совместимого шлюза |
| `EMBEDDING_BASE_URL` | для OpenAI: `https://api.openai.com/v1` |
| `EMBEDDING_MODEL`, `EMBEDDING_DIMENSION` | модель эмбеддингов и размерность (`text-embedding-3-small`, 1536) |
| `CHAT_MODEL` | модель для диалога (например `gpt-4o-mini`) |
| `CHAT_REASONING_EFFORT` | для рассуждающих моделей поставьте `none`, иначе вызов инструментов вернёт ошибку 400; для обычных оставьте пустым |
| `TELEGRAM_BOT_TOKEN` | токен бота |
| `SEARCH_TOP_K`, `MIN_SCORE`, `HISTORY_LIMIT` | сколько результатов искать (3), порог релевантности (0.25), сколько реплик помнить в разговоре (10) |

Для `text-embedding-3-large` укажите `EMBEDDING_DIMENSION=3072` и новое имя индекса: размерность существующего индекса менять нельзя.

## Запуск
```bash
python test_embedding.py   # проверка: эмбеддинг создаётся
python upload_data.py      # создать индекс и загрузить факты (достаточно один раз)
python search.py           # проверить поиск на примерах (или: python search.py "ваш запрос")
python bot.py              # запустить бота
```
Повторная загрузка безопасна: записи перезаписываются по ID, дублей не будет.

## Примеры запросов к базе фактов
| Запрос | Что найдёт | Почему |
|---|---|---|
| Что можно хранить тысячелетиями и не бояться порчи? | `fact-001` | мёд из гробниц |
| Необычные явления на других планетах и звёздах | `fact-003`, `fact-010` | Венера и нейтронная звезда |
| Как металлические конструкции реагируют на погоду? | `fact-004` | Эйфелева башня расширяется от жары |
| Выдающиеся учёные и их уникальные достижения | `fact-020` | Мария Кюри и две Нобелевские премии |
| Истоки компьютерной эпохи | `fact-015`, `fact-023` | первый «баг» и первое сообщение ARPANET |

Точные значения релевантности зависят от модели.

## Структура проекта
| Файл | Назначение |
|---|---|
| `bot.py` | Telegram-бот: команды и обработка сообщений |
| `chat.py` | диалог с моделью, подмешивание контекста, вызов инструментов памяти |
| `memory.py` | запись, чтение и удаление воспоминаний в Pinecone |
| `search.py` | семантический поиск `semantic_search()` |
| `embeddings.py` | клиент OpenAI: эмбеддинги и обработка ошибок |
| `pinecone_store.py` | подключение к Pinecone, создание индекса |
| `data.py` | база фактов |
| `upload_data.py` | пакетная загрузка фактов в Pinecone |
| `test_embedding.py` | быстрая проверка эмбеддингов |
| `config.py` | чтение настроек из `.env` |

## Свои данные
Замените список в `data.py` своими записями (`id`, `topic`, `text`; ID и тексты должны быть уникальными) и снова запустите `python upload_data.py`.

## Частые проблемы
| Симптом | Решение |
|---|---|
| «Неверный API-ключ» | проверьте `EMBEDDING_API_KEY` и `EMBEDDING_BASE_URL` |
| «Модель или URL не найдены» | `EMBEDDING_BASE_URL` должен оканчиваться на `/v1`; проверьте `EMBEDDING_MODEL` и `CHAT_MODEL` |
| Ошибка 400 про `reasoning_effort` | у рассуждающей модели поставьте `CHAT_REASONING_EFFORT=none` |
| Ошибка 400 про `dimensions` | модель эмбеддингов не поддерживает этот параметр (например, `ada-002`): уберите его в `embeddings.py` |
| Размерность индекса не совпадает | индекс создан под другую модель: смените `PINECONE_INDEX_NAME` |
| Только что сохранённое не находится | Pinecone обновляется с задержкой в несколько секунд |
| Бот молчит | неверный токен или запущен второй экземпляр бота |

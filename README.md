# Бот «Интересные факты» — поиск по смыслу

Telegram-бот, который находит интересные факты **по смыслу**, а не по совпадению слов. Вы пишете вопрос или тему своими словами, а бот возвращает самые близкие по смыслу факты из базы.

> Запрос: *«Что можно хранить тысячелетиями и не бояться порчи?»*
> Ответ: факт про мёд из египетских гробниц, хотя слова «мёд» в запросе нет.

## Что умеет бот
- Понимает смысл запроса: «необычное про планеты» найдёт факты про Венеру и нейтронные звёзды.
- Возвращает 3 самых релевантных факта (число настраивается).
- Показывает для каждого факта текст, процент релевантности, тему и ID записи.
- Понятно сообщает об ошибках: недоступный API, неверный ключ, пустой запрос.
- Отвечает на команды `/start` и `/help`.

В базе 24 факта на разные темы: космос, животные, история, наука, технологии, природа и другие.

## Как это работает
1. Каждый факт превращается в вектор (1536 чисел) с помощью модели эмбеддингов OpenAI `text-embedding-3-small`.
2. Векторы вместе с текстом хранятся в Pinecone, векторной базе данных.
3. Вопрос пользователя превращается в такой же вектор, и Pinecone находит ближайшие по косинусной близости факты.

## Технологии
- Python 3.13
- [Pinecone](https://www.pinecone.io): serverless-индекс, метрика cosine
- OpenAI Embeddings API (подходит и любой OpenAI-совместимый шлюз)
- python-telegram-bot

## Установка
```bash
py -3.13 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```
Затем заполните `.env` (см. ниже). Файл `.env` в git не попадает.

## Настройка
Понадобятся три ключа:
- **Pinecone**: ключ из раздела API Keys в консоли. Индекс создавать вручную не нужно, он создастся при первой загрузке данных.
- **OpenAI**: ключ с платформы OpenAI. Эмбеддингов на всю базу хватит нескольких центов.
- **Telegram**: токен бота от [@BotFather](https://t.me/BotFather).

| Переменная | Смысл |
|---|---|
| `PINECONE_API_KEY` | ключ Pinecone |
| `PINECONE_INDEX_NAME`, `PINECONE_CLOUD`, `PINECONE_REGION`, `PINECONE_NAMESPACE` | параметры индекса (по умолчанию `interesting-facts`, `aws`, `us-east-1`, `facts`) |
| `EMBEDDING_API_KEY` | ключ OpenAI или совместимого шлюза |
| `EMBEDDING_BASE_URL` | для OpenAI: `https://api.openai.com/v1` |
| `EMBEDDING_MODEL`, `EMBEDDING_DIMENSION` | модель и размерность вектора (`text-embedding-3-small`, 1536) |
| `TELEGRAM_BOT_TOKEN` | токен бота |
| `SEARCH_TOP_K` | сколько фактов возвращать (по умолчанию 3) |

Для `text-embedding-3-large` укажите `EMBEDDING_DIMENSION=3072` и новое имя индекса: размерность существующего индекса менять нельзя.

## Запуск
```bash
python test_embedding.py   # проверка: эмбеддинг создаётся
python upload_data.py      # создать индекс и загрузить факты
python search.py           # проверить поиск на примерах (или: python search.py "ваш запрос")
python bot.py              # запустить бота
```
Загрузку данных достаточно выполнить один раз. Повторный запуск безопасен: записи перезаписываются по ID, дублей не будет.

## Примеры запросов
| Запрос | Что найдёт | Почему |
|---|---|---|
| Что можно хранить тысячелетиями и не бояться порчи? | `fact-001` | мёд из гробниц |
| Необычные явления на других планетах и звёздах | `fact-003`, `fact-010` | Венера и нейтронная звезда |
| Как металлические конструкции реагируют на погоду? | `fact-004` | Эйфелева башня расширяется от жары |
| Выдающиеся учёные и их уникальные достижения | `fact-020` | Мария Кюри и две Нобелевские премии |
| Истоки компьютерной эпохи | `fact-015`, `fact-023` | первый «баг» и первое сообщение ARPANET |

Точные значения релевантности зависят от модели.

## Структура проекта
| Файл | Назначение |
|---|---|
| `bot.py` | Telegram-бот |
| `search.py` | семантический поиск `semantic_search()` |
| `embeddings.py` | получение эмбеддингов с обработкой ошибок |
| `pinecone_store.py` | подключение к Pinecone, создание индекса |
| `data.py` | база фактов |
| `upload_data.py` | пакетная загрузка фактов в Pinecone |
| `test_embedding.py` | быстрая проверка эмбеддингов |
| `config.py` | чтение настроек из `.env` |

## Свои данные
Замените список в `data.py` своими записями (`id`, `topic`, `text`; ID и тексты должны быть уникальными) и снова запустите `python upload_data.py`.

## Частые проблемы
| Симптом | Решение |
|---|---|
| «Неверный API-ключ» | проверьте `EMBEDDING_API_KEY` и `EMBEDDING_BASE_URL` |
| «Модель или URL не найдены» | `EMBEDDING_BASE_URL` должен оканчиваться на `/v1`; проверьте имя модели |
| Ошибка 400 про `dimensions` | модель не поддерживает этот параметр (например, `ada-002`): уберите его в `embeddings.py` |
| Размерность индекса не совпадает | индекс создан под другую модель: смените `PINECONE_INDEX_NAME` |
| Поиск пуст сразу после загрузки | Pinecone обновляется с задержкой, подождите несколько секунд |
| Бот молчит | неверный токен или запущен второй экземпляр бота |
